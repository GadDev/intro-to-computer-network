# Introduction to Computer Networks

A beginner-friendly course and presentation companion for the TCP vs UDP File Transfer project.

The first page explains the TCP file transfer and lets you step through an illustrative UDP loss and recovery sequence. It uses Astro, TypeScript, and CSS. All content and controls work locally after the static build.

## Run locally

Use Node.js 24 and npm.

```sh
npm ci
npm run dev
```

Run `npm run check` for type checks. For an offline rehearsal, run `npm run build` and `npm run preview`, then open the local address printed by Astro.
